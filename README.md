*I run the software side at SAYNET Mühendislik — IoT telemetry, full-stack web/mobile, and AI-assisted development workflows. Based in Türkiye.*

### Neler yapıyorum

- **Yapay zekâ ile yazılım geliştirme:** Claude Code, MCP sunucuları, planlayıcı → uygulayıcı ajan akışları
